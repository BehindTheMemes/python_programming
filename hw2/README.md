### Трекер книг

list выбран для хранения изменяющегося набора книг, потому что в него можно добавлять новые записи с помощью append. 
tuple используется для одной книги, так как её структура фиксирована: (id, автор, название, год).
dict хранит книги по id, поэтому нужную запись можно быстро получить по ключу.
set используется для жанров, потому что в нём сохраняются только уникальные значения.
